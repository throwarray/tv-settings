# TV Settings

Per-app control and hidden settings for Fire TV and Android TV, built with Jetpack Compose and driven by a D-pad.

## Features

- **Apps:** filter, sort (including Active, CPU and RAM) and search. Each app shows its Details, Actions, Permissions, Services and Activities.
- **Advanced:** debloating, privacy toggles, appearance, location, controls and other functionality.
- **VPN dot:** monitor VPN status with a floating indicator in the corner of the screen.
- **Widget:** Now Playing and CPU and RAM stats for your launcher.

## Setup

1. Install the APK.
2. Start Shizuku, then authorise the app in Advanced → Status.

## Notes

- Features marked * need [Shizuku](https://shizuku.rikka.app/) running.
- Code and assets are generated with guided assistance from Claude or other AI services.
- Work in progress. Expect there to be bugs or breaking changes.
